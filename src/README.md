# React Practice Tic-Tac-Toe

## English

This project is a Tic-Tac-Toe game implemented in React as part of my learning journey following the ["React - The Complete Guide 2024 (incl. React Router & Redux)"](https://www.udemy.com/share/101Wby3@-TeKYv_zeACyKbjnVJ9cjR-QxwxIR_vW6NxNj3Vb6MNNJO_kt4xi00uspSsSRwMTmA==/) course on Udemy.

### About This Project

This implementation was created for educational purposes to practice essential React concepts such as:

- Components and Props
- State Management with useState
- Conditional Rendering
- Event Handling
- Lists and Keys
- Lifting State Up
- Derived State

### Disclaimer

The code structure and logic follow the course instructor's guidance. This is not an original project but rather a practical exercise to reinforce React fundamentals.

### Technologies Used

- React 19.0.0
- Vite
- CSS3
- JavaScript (ES6+)
